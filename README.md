# Simo B2 Listening — five short recordings

**Live exam:** https://paulos78.github.io/simo-b2-first-listening/

Original B2-level listening skills assessment (not the exact Cambridge B2 First exam format):

- 45-minute timed exam, five recordings (about 2.6–3.2 minutes each).
- Six multiple-choice questions per recording = 30 questions, each worth one mark.
- Questions assess attitudes, implications, specific details and changes of opinion.
- Browser autosaves progress and automatically scores answers on submission.
- With the student's consent, the test sends a full answer report using FormSubmit to the teacher's reporting endpoint; results can also be saved as CSV.
- The audio currently uses macOS-generated narrators, **not ElevenLabs**. ElevenLabs audio generation was blocked by a connection security check. Do not claim the current recordings are ElevenLabs.

The teacher-reporting endpoint comes from the pre-existing B2 mock project. Actual email delivery depends on account activation and external email service availability. There is no central database. A private credential must never be embedded in the public repository.
