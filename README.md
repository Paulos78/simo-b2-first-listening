# Simo's Cambridge B2 First-style Listening Mock

Independent, original **45-minute** B2 First-style listening examination for Simone.

**Student link:** https://paulos78.github.io/simo-b2-first-listening/

## Paper layout
- Part 1: Multiple choice — eight short recordings; 8 questions.
- Part 2: Sentence completion — one longer talk; 10 questions.
- Part 3: Multiple matching — five speakers and eight statements; 5 questions.
- Part 4: Multiple choice — a long interview; 7 questions.
- Total: **30 marks across 30 questions**; each recording is played twice, with a 45-minute clock.

## Reporting
The exam checks answers automatically. Results, explanations and the complete answer list are shown to Simo after submission. Students can download a CSV, copy the answer report or print to PDF. With consent, the site **submits** the answer report via FormSubmit to the same teacher notification endpoint used in the existing B2 First mini mock. Email acceptance or delivery requires a working FormSubmit endpoint; successful delivery has not been independently verified. The full report is also saved locally in the browser until the attempt is cleared.

## Hosting and implementation
Static HTML, CSS, JavaScript, MP3 recordings, and GitHub Pages. Audio was generated using offline macOS narration voices, **not ElevenLabs**. The audio scripts, answers and teacher reporting code are authored as independent practice material. The code makes no claims of Cambridge affiliation or Cambridge grading equivalence. GitHub Pages hosts a client-side app, not a central results database: teacher reporting uses email rather than a server-side database.
